# ogarnijfizyke.pl

A free physics course for the Polish *matura* (the high-school final exam), built around my YouTube channel [@tomekstolarczykk](https://www.youtube.com/@tomekstolarczykk).

**Live:** [ogarnijfizyke.pl](https://ogarnijfizyke.pl)

## Stack

Next.js · TypeScript · React · Tailwind CSS 

## How it was built

This website was largely made with AI tools (Claude Code). The idea, the course, the design decisions and every review are mine; AI took over the typing, both to automate the process and so I could learn to work with these tools. My core skills are C/C++, and these were not harmed in the process ;)

## Running locally

```bash
npm install
npm run dev
```
